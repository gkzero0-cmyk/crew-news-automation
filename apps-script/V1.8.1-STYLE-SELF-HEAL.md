# Apps Script v1.8.1 색상 자가복구 설치

기존 `Code.gs`와 `ControlAuditV180.gs`는 그대로 둡니다.

1. Apps Script 프로젝트에서 새 스크립트 파일 `StyleSelfHealV181.gs`를 추가합니다.
2. 저장소의 `apps-script/StyleSelfHealV181.gs` 전체 내용을 붙여넣고 저장합니다.
3. 함수 목록에서 `installCrewNewsStyleSelfHealV181`을 1회 실행합니다.
4. 기존 `refreshCrewNewsV180` 30분 트리거는 제거되고 `refreshCrewNewsV181` 트리거 하나로 교체됩니다.
5. 새 트리거는 기존 v1.8 갱신을 그대로 실행한 뒤 크루명 고유색만 검사해 필요한 셀만 다시 씁니다.

정상 상태에서는 `자동화 상태`의 `ScriptVersion`이 `crew-apps-script-v1.8.1`로 표시됩니다.
