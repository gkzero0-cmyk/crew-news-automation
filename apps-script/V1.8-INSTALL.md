# Apps Script v1.8 설치

이 버전은 기존 `Code.gs`를 교체하지 않고 `ControlAuditV180.gs`를 추가해 안전 계층만 덧붙입니다.

## 1회 설치

1. 대상 Google Sheet에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 새 스크립트 파일을 만들고 이름을 `ControlAuditV180`으로 지정합니다.
3. 저장소의 `apps-script/ControlAuditV180.gs` 전체 내용을 붙여넣고 저장합니다.
4. 함수 선택에서 `installCrewNewsAutomationV180`을 선택해 한 번 실행하고 권한을 승인합니다.
5. 이후 30분 자동 갱신은 `refreshCrewNewsV180` 트리거가 담당합니다. 설치 시 기존 `refreshCrewNews` 시간 트리거는 제거됩니다.

## 동작 확인

- `자동화 상태`의 `ScriptVersion`이 `crew-apps-script-v1.8.0`인지 확인합니다.
- `자동화 제어`는 `자동 / 임시 고정 / 영구 고정`을 사용할 수 있습니다.
- `자동화 판정 이력`에는 서버의 선택/후보/제외 판정이 변경될 때 누적됩니다.
- 후보 0건으로 메인 소식을 비우는 동작은 서버가 `clearVerified=true`까지 증명한 경우에만 허용됩니다.

## 제어 모드

- **자동**: 서버의 정상 판정을 그대로 반영합니다.
- **임시 고정**: 현재 소식을 보호합니다. 고정 시점보다 뒤에 게시된 서로 다른 적합 소식이 확인되면 자동으로 `자동`으로 복귀합니다.
- **영구 고정**: 운영자가 직접 `자동`으로 바꿀 때까지 현재 소식을 유지합니다.

## 롤백

`uninstallCrewNewsAutomationV180`을 실행하면 v1.8 시간/열기 트리거가 제거됩니다. 기존 `Code.gs`는 그대로 남으므로 필요하면 기존 설치 함수로 되돌릴 수 있습니다.

> v1.8 설치 뒤에는 수동 갱신도 기존 `크루 자동화` 메뉴가 아니라 **`크루 자동화 v1.8 → 지금 안전 갱신`**을 사용합니다.
